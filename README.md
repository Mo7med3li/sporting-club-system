# Sporting Club Frontend App

## Description

This is a simple frontend application for a sporting club system.  
Users can:

- View a list of sports
- Add a new sport
- View a list of members
- Add a new member
- Subscribe members to sports
- Prevent subscribing to the same sport twice

The app uses **React**, **TypeScript**, **React Hook Form**,**Shadcn UI** and **localStorage** to mock backend data.

---

## Features

### Core Features

- **Sports Page**: Display all sports and add a new sport
- **Members Page**: Display all members and add a new member
- **Subscriptions**: Subscribe a member to one or more sports while preventing duplicates

### Bonus Features

- Form validation with Zod
- Responsive layout
- Clean and reusable components

## Setup Instructions

1. Clone the repository:

git clone <your-repo-link>

2-Navigate to the project folder:

cd <project-folder>

3-Install dependencies:

yarn

4-Start the development server:

yarn dev

5-Open the app in your browser:

http://localhost:3000
